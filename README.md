# WorkautLM

Нативное iOS-приложение для ведения тренировок, восстановления и повседневных заметок по питанию.

`WorkautLM` помогает превратить сырой план от AI-ассистента в структурированную тренировку, пройти сессию с таймером и чеклистом, а затем экспортировать результат в Markdown для Obsidian/NotebookLM.

## Возможности

- Умный парсер тренировок из вставленного текста (таблица + рекомендации).
- Экран выполнения тренировки с подходами, отметкой выполнения и фиксацией времени.
- Таймер отдыха (в т.ч. с Live Activity).
- Редактирование фактических весов/повторений прямо во время тренировки.
- Экспорт отчета тренировки в Markdown с шарингом.
- Экран абонемента (пропуск) с визуальным статусом срока действия.
- Тёмная тема интерфейса с акцентом на фиолетовый цвет.

## Стек

- Swift
- SwiftUI
- SwiftData
- ActivityKit / WidgetKit
- Xcode 26+

## Структура проекта

- `Workout/` — основное приложение (SwiftUI views, модели, парсер).
- `WorkoutWidget/` — виджет и Live Activity extension.
- `Media/` — медиа-ресурсы для документации/брендинга.

Ключевые файлы:

- `Workout/Workout/SmartPlanParserView.swift` — импорт и разбор AI-плана.
- `Workout/Workout/WorkoutExecutionView.swift` — основной экран тренировки.
- `Workout/Workout/GymPassView.swift` — экран абонемента.
- `Workout/Workout/Models.swift` — SwiftData-модели.

## Требования

- macOS с установленным Xcode 26+
- iOS 26+ для полного UX с Liquid Glass/Live Activity фичами
- Apple Developer account (опционально, для деплоя на устройство)

## Запуск

1. Откройте проект:

```bash
open Workout.xcodeproj
```

2. В Xcode выберите схему `Workout`.
3. Выберите симулятор/устройство и запустите `Run`.

## Базовая проверка

Сборка из терминала:

```bash
xcodebuild build -project Workout.xcodeproj -scheme Workout -destination 'platform=iOS Simulator,name=iPhone 17'
```

## Рекомендуемый пользовательский flow

1. Вставить AI-план в `Умный парсер`.
2. Сохранить сессию и открыть экран `Тренировка`.
3. Отмечать подходы и корректировать фактические значения.
4. Экспортировать итог в Markdown и отправить в Obsidian/NotebookLM.
